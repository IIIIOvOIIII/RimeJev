# Implementation baseline

0.2.4 provides two decision backends, an asynchronous native coordinator, stable genuine-candidate identity, per-application enablement, context continuity, compact source labels, and failure fallback.

The original first candidate is preserved. A matching model choice receives a short source label; a different choice occupies the second position with a recommendation label. Space and numeric selection always use the displayed engine order.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the current contract, [VALIDATION.md](VALIDATION.md) for evidence boundaries, and [LLM_INSTALL.md](../LLM_INSTALL.md) for executable installation steps. Historical private setup logs, screenshots, service endpoints, and credentials are intentionally not part of this public source snapshot.
